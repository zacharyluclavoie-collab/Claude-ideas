# Gem Rush

A one-file portrait clicker built for screen recording. Tap the gem, grab upgrades, and watch it evolve through 8 tiers (Quartz → Citrine → Emerald → Sapphire → Ruby → Amethyst → Diamond → Cosmic).

Open `index.html` in any browser. No build step, no dependencies.

## What's in it

- Procedurally drawn faceted gem with a moving light sweep, squash-and-tilt on every tap, and orbiting sparks that grow with each tier
- Combo meter (tap fast for up to x3), crits, and milestone callouts (NICE, SWEET, INSANE, UNREAL, GODLIKE)
- Golden gem flies across the screen. Tap it for Frenzy: everything x7 for 15 seconds
- 8 upgrades from Sharp Pick to Black Hole, with a full-screen evolve moment at every tier
- Synth sound (pentatonic, climbs with your combo), haptics, offline earnings, autosave

## Recording for TikTok

1. Host it (see below) and open it on your phone. Add it to your home screen for a full-screen view with no browser bar.
2. Turn on **Auto-play** (the circle button, top right). It taps with a human rhythm, buys upgrades, and grabs golden gems, so you can start the screen recording and let it run.
3. Use the reset button (tap it twice) to start fresh for each take. The first 30 seconds show the whole hook: tap, combo, first evolve.

Video ideas that fit the game:

- "Tap this gem until it evolves" with a counter overlay, ending on Cosmic
- "POV: you find the golden gem" cutting to Frenzy
- Duet or stitch with "can you beat my tier?" and the share button text

## Hosting

Any static host works. For GitHub Pages: Settings → Pages → deploy from the branch root, then open `https://<user>.github.io/<repo>/`.
